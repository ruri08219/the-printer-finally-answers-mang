One line, in the office printer's own voice, as its comeback to the jams, the error codes and the thumps.

`main.py` (Python 3 standard library only) writes the line to `/output/entry.txt`:

> I have fed this office 41,209 sheets. You remember one of them: the jam.

Run: `python3 main.py`
